## 交互映射

1. 左侧仍是可操作的会话列表，以灰色选中底和古金标记表达任务日志感。
2. 对话保留实际标题、消息与公开推理摘要；运行状态继续来自 AgentUX。
3. 现有输入建议显示编号，点击仍填入输入框。
4. 输出区保留真实产物；截图中的同行小队属于额外的多 Agent 产品功能，不生成虚假的队员或状态。
5. 小屏缩小头像和横幅，建议按钮换行；字体大小不随窗口比例缩放。

## 素材与导出

三张 WebP 均裁自用户提供的参考截图，合计约 25 KB：
