# 十套换肤风格方案

## 0. theme 与 style 的分工（先定这个，否则 10 套会失控）

| | theme（配色） | style（换肤） |
|---|---|---|
| 载体 | `ThemeTokens` 一条记录 | `PresetStyleId` + `app.css` 一条分支 |
| 能表达 | 色、字体栈、明暗 | 几何、描边、投影、密度、图标画法、窗口 chrome |
| 现有数量 | 27（含新加的 10 套 atlas） | **3**：原生风 / 极简风 / 插画风 |
| 加一套的成本 | 约 20 行 | 约 150–250 行 CSS + 图标处理 + 头像默认值 |

本文规划的是 **style**。10 套 = 现有 3 + 新增 7。

### ⚠️ 先做基建，否则第 10 套会写不动

做插画风时暴露的问题：每条规则都得自己写一遍 `border`/`radius`/`shadow`，改一个
描边粗细要改十几处。10 套这样堆，`app.css` 会再长几千行且互相不可比。

**建议先把 style 层收成一张值表** —— 每套风格只定义下面这组 custom property，
组件侧统一读它们：

```css
.preview-frame[data-style-preset="X"] {
  --sk-edge-width:      /* 0 | 1px | 2px | 3px | 4px */
  --sk-edge-color:      /* token */
  --sk-edge-style:      /* solid | outset | inset | double | none */
  --sk-radius-scale:    /* 0 | 4 | 8 | 12 | 20 */
  --sk-elevation:       /* none | soft | hard-offset | bevel | dual */
  --sk-density:         /* compact | normal | airy */
  --sk-icon-mode:       /* line | filled | chip | pixel | os-glyph */
  --sk-chrome:          /* none | titlebar | numbered | tabbar */
}
```

这样加一套风格 ≈ 填一行表 + 3–5 条特例规则，而不是重写一套组件样式。
**这件事该在第 4 套之前做，不是之后。**

## 1. 变化轴（10 套的区分依据）

每套风格在这 9 条轴上取值。任意两套至少在 **4 条**上不同 —— 这是"10 套不重复"的
可验证标准，不靠感觉。

1. **明暗** light / dark
2. **色彩策略** 单信号色 / 双色 / 多色分区块 / 无彩
3. **字族** 几何无衬线 / 中性无衬线 / 衬线 / 等宽 / 点阵
4. **描边** 无 / 1px 发丝 / 2–4px 重墨 / 立体斜角 / 双线
5. **圆角** 0 / 4 / 8 / 12 / 20+
6. **投影** 无 / 柔和模糊 / 硬位移 / 斜角浮雕 / 双向柔光
7. **密度** 紧凑 / 常规 / 疏阔
8. **图标画法** 线 / 填色字形 / 容器贴片 / 点阵 / 系统字形
9. **窗口隐喻** 无 / 系统标题栏 / 编号分区 / 标签页栏

### 新增 7 套

#### 4. 系统原生 · Classic OS（Win9x/2000）

> 参考里出现了**两次**（老 QQ、Alma），是最想做的一套。

| 轴 | 取值 |
|---|---|
| 明暗 | light |
| 色彩 | 无彩灰 `#C0C0C0` + 标题栏蓝渐变 `#0A246A → #A6CAF0` |
| 字族 | 系统 11px（Tahoma / MS Sans / PingFang 12px） |
| 描边 | **立体斜角**：上左 `#FFFFFF`，下右 `#808080`，外圈 `#000` |
| 圆角 | **0** |
| 投影 | 斜角浮雕（非阴影） |
| 密度 | 紧凑 |
| 图标 | 系统字形（复用现成的 codicon 通路） |
| chrome | **系统标题栏** + `_ □ ×` |

**UI 变化**
- 会话列表 → 带 `inset` 凹陷边框的列表框，选中行为**蓝底白字**反白（非圆角高亮）
- 消息气泡 → 方角 `outset` 面板，无圆角无阴影
- 输入框 → `inset` 凹陷 2px，插入符闪烁
- 按钮 → `outset` 凸起，按下瞬间切 `inset` 并整体位移 1px
- 工具卡 → 带标题栏的子窗口，右上角 `×`
- 滚动条 → 方块滑块 + 两端箭头按钮

**实现要点**：斜角靠 `border-style: outset/inset` 或四边异色 `border-color` 即可，
不需要图片。`--sk-chrome: titlebar` 需要组件层加一个标题栏槽位 —— 这是 7 套里唯一
需要**新结构**的。

#### 5. 像素终端 · Pixel Terminal

> 参考 2（小语文稿）。

| 轴 | 取值 |
|---|---|
| 明暗 | **dark** |
| 色彩 | 石板 `#1E212B` + 荧光绿 `#7CE38B` + 品红 `#D89BF5` |
| 字族 | **点阵等宽**（全局，含正文） |
| 描边 | 1px 硬边，无抗锯齿感 |
| 圆角 | **0** |
| 投影 | **无** |
| 密度 | 紧凑 |
| 图标 | **点阵**（16px 网格手绘 SVG）+ emoji 作目录图标 |
| chrome | 标签页栏 |

**UI 变化**
- 文件名带 `.md` 后缀且后缀降为 muted 色（参考图的细节）
- 行高压到 1.35，字距略放
- 选中态 = 1px 左侧竖条 + 极浅底，不用圆角
- `image-rendering: pixelated` 给头像
- 状态不用图标，用 `[OK]` `[..]` 这类文本标记

#### 6. 牛皮纸 · Zine

> 参考 4（Raft/Botiverse）。

| 轴 | 取值 |
|---|---|
| 明暗 | light |
| 色彩 | 米黄 `#FDF6E3` + 纯黑 + 品红 `#FF6B9D` 单点 |
| 字族 | 等宽标签 + 中性无衬线正文 |
| 描边 | **1px 纯黑发丝**，处处成框 |
| 圆角 | 2–4（近方） |
| 投影 | **无**（完全扁平） |
| 密度 | 常规 |
| 图标 | 线 + 点阵头像 |
| chrome | 左侧窄图标轨 |

**UI 变化**
- 分区标题 → **全大写等宽 + 字距 0.08em**，像标签而非标题
- 统计数字 → 1px 黑框方块并排，无填充
- 选中态 → 品红实底 + 黑框
- 与插画风的区别：**描边 1px 而非 3px、完全无投影、米黄而非紫** —— 4 条轴不同

#### 7. Y2K 极繁 · Maximalist

> 参考 5（RetroBot）。

| 轴 | 取值 |
|---|---|
| 明暗 | light |
| 色彩 | **多色分区块**：品红 / 亮绿 / 橙 / 紫，每个区域一个色 |
| 字族 | 等宽 |
| 描边 | **4px 纯黑** |
| 圆角 | **0** |
| 投影 | **硬位移 `6px 6px 0 #000`** |
| 密度 | 疏阔 |
| 图标 | emoji + 填色字形 |
| chrome | **编号分区**（`1. NEW CHAT` / `3. CHAT WINDOW`） |

**UI 变化**
- 每个 region 拿到**不同的**底色，靠 `--sk-region-tint` 按区分配
- 区块标题 → 黑底白字小方块，带序号
- 标题区 → 渐变横幅
- 这是唯一一套**多色分区**的，与所有其它风格在"色彩策略"轴上正交

#### 8. 拟物 · Neumorphic

| 轴 | 取值 |
|---|---|
| 明暗 | light |
| 色彩 | 单一灰 `#E4E7EC`，几乎无对比 |
| 字族 | 几何无衬线，字重偏轻 |
| 描边 | **无** |
| 圆角 | **20+** |
| 投影 | **双向柔光**：`-6px -6px 12px #FFF, 6px 6px 12px #C5CAD3` |
| 密度 | 疏阔 |
| 图标 | 线，同底色 + 投影 |
| chrome | 无 |

**UI 变化**
- 所有控件从背景**挤出来或压进去**，没有一条边框线
- 按下 → 投影内外翻转（凸变凹）
- 选中态 = 凹陷，而非变色
- **与前面每一套都最远** —— 它把"描边"这条轴取到了 0，其它风格全在 1–4px

---

#### 9. 玻璃 · Liquid Glass

| 轴 | 取值 |
|---|---|
| 明暗 | dark（底层彩色渗透） |
| 色彩 | 半透明白 + 背景色渗透 |
| 字族 | 中性无衬线 |
| 描边 | 1px 半透明白 |
| 圆角 | 16 |
| 投影 | 柔和 + `backdrop-filter: blur()` |
| 密度 | 常规 |
| 图标 | 线，半透明 |
| chrome | 无 |

**UI 变化**
- 面板 `background: rgba(255,255,255,.08)` + `backdrop-filter: blur(24px)`
- 需要画布背景有**内容可透** —— 配一张渐变/图片底，否则毛玻璃看不出
- 边框用 `linear-gradient` 描边模拟高光边

**风险**：`backdrop-filter` 在导出的脚手架里依赖层叠上下文，且移动端性能敏感。
这套建议排在后面做。

#### 10. 报刊 · Editorial Print

| 轴 | 取值 |
|---|---|
| 明暗 | light |
| 色彩 | 纸白 `#FBFAF7` + 墨黑 + 朱红单点 |
| 字族 | **衬线**（标题大号衬线，正文衬线） |
| 描边 | **只有横线（`border-top`），不成框** |
| 圆角 | **0** |
| 投影 | 无 |
| 密度 | **疏阔**（行高 1.7） |
| 图标 | 线，极细 |
| chrome | 无 |

**UI 变化**
- **这是唯一一套不用"盒子"的** —— 分隔靠水平细线和留白，卡片概念退场
- 消息不做气泡，靠**左侧作者名 + 缩进**区分，像访谈排版
- 工具调用 → 折叠的脚注样式
- 与极简风的区别：衬线、0 圆角、无盒、行高 1.7 —— 4 条轴不同

## 3. 区分度自检

| 对 | 相同轴数 | 判定 |
|---|---|---|
| 插画风 vs 牛皮纸 | 描边粗细/投影/色彩/圆角 4 项不同 | ✅ |
| 插画风 vs Y2K | 色彩策略/描边/圆角/chrome 4 项不同 | ✅ |
| 牛皮纸 vs Y2K | 描边 1px vs 4px、投影、色彩、密度 | ✅ |
| 极简风 vs 报刊 | 字族/圆角/成框/密度 | ✅ |
| 拟物 vs 全部 | 描边=0、双向柔光，独占 | ✅ |
| 像素终端 vs 系统原生 | 明暗/字族/描边/圆角 | ✅ |

## 4. 建议排期

| 批次 | 风格 | 理由 |
|---|---|---|
| **0** | **style 值表基建**（§0） | 不做这个，后面每套都是手写 |
| 1 | 系统原生、Y2K 极繁 | 参考最明确、视觉差异最大、最能验证基建 |
| 2 | 牛皮纸、报刊 | 纯 CSS，无新结构，最快 |
| 3 | 像素终端、拟物 | 前者要手绘点阵图标，后者要调投影配方 |
| 4 | 玻璃 | `backdrop-filter` 有导出与性能风险，压后 |

**系统原生**是 7 套里唯一需要新组件结构的（标题栏槽位）；其余 6 套都能靠值表 +
少量特例 CSS 完成。

## 5. 每套风格的交付清单

1. `PresetStyleId` 加成员 + `presetStyleIds`
2. `presetStyleOptions` 加标签（en/zh/ja 三语）
3. 至少 1 套专属 theme（`themeTokens.ts` + `themeDirections` + `themeOptions` 映射）
4. `defaultThemeForStyle()` 加分支
5. `STYLE_AVATAR_DEFAULTS` 加条目
6. `app.css` 的 `[data-style-preset="X"]` 值表 + 特例
7. 图标处理（`--sk-icon-mode`，点阵风格需手绘 SVG）
8. 导出校验：`scaffoldStyles.ts` 以 `?raw` 内联 `app.css`，样式自动随包走；
   但 `IconStyleProvider` 的三元判断（`App.tsx` / `scaffoldManifest.ts`）要同步
